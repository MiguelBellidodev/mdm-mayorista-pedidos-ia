# Arquitectura Técnica: MDM Mayorista - Sistema de Pedidos y Catálogo con IA

- Cliente: MDM Mayorista (Av. Juan B. Justo 3636, Córdoba Capital)
- Repositorio: https://github.com/MiguelBellidodev/mdm-mayorista-pedidos-ia
- Deploy: https://mdm-mayorista-pedidos-ia.vercel.app

## Stack Tecnológico
- Frontend: React 19 + TypeScript + Tailwind CSS
- Backend: API REST Node.js
- Base de Datos: PostgreSQL / Supabase (schema.sql)
- Automatización: n8n + Webhook WhatsApp Business
- Despliegue: Vercel Production
